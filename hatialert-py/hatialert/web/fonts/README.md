# Fonts

Bundled so the app looks the same offline. Latin subsets from Fontsource 5.3.0.

- Atkinson Hyperlegible (Braille Institute of America) — body text
- Bricolage Grotesque (Mathieu Triay) — headings
- IBM Plex Mono (IBM) — report numbers and coordinates
